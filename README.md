# MUET Alumni Management System — Setup

This is a single-file web app (`index.html`). It runs entirely in your browser using CDN
libraries (SheetJS for Excel/CSV, jsPDF + html2canvas for PDFs, JSZip for bulk downloads) and
saves data in the browser's local storage — no backend, no install.

## ⚠️ Run it via a local server, not by double-clicking the file

**PDF generation (Preview → Download PDF, and the ZIP bulk export) requires the page to be
served over `http://`, not opened as a bare `file://` path.** Browsers block canvas image
export ("PDF blocked by the browser…") when a page is opened by double-clicking, because the
security rules around `file://` pages are stricter than normal web pages. The rest of the app
(dashboard, forms, Excel import, records) works fine either way — only PDF export needs this.

Pick whichever is easiest:

- **Python installed:** open a terminal in this folder and run:
  ```
  python3 -m http.server 8000
  ```
  then open `http://localhost:8000` in your browser.
- **Node.js installed:** run `npx serve -l 8000 .` in this folder, then open `http://localhost:8000`.
- **VS Code:** install the "Live Server" extension, right-click `index.html` → "Open with Live Server".
- Or host the folder on any static web host (school intranet, GitHub Pages, Netlify, etc.) —
  PDF export works there too since it's already served over http(s).

If your terminal says something like *"Python was not found, run without arguments to install
from the Microsoft Store"*, Python isn't actually installed — use the Node.js or VS Code option
instead, or install Python properly from python.org first.

## Student photos (optional)

Student photos are auto-detected from the Roll Number if you place image files next to
`index.html` like this:

```
/ (any folder)
  index.html
  images/
    24bscs034.jpg
    24bscs035.jpg
    ...
```

- File name = Roll Number in **lowercase, with spaces removed**, e.g. `24bscs034.jpg` for Roll
  Number `24BSCS034`.
- No photo on disk? You can instead upload one directly per-student in Add/Edit Alumni — it's
  stored with that record in the browser.
- Still no photo at all? A clean placeholder with the student's initials is shown — never a
  broken image icon.

## Logos

The MUET logo and Alumni Office logo are embedded directly inside `index.html` (as the actual
official images), so they always display correctly with no internet connection needed and no
risk of a broken image. They show top-right on every CV and the MUET logo in the sidebar. Go to
**Settings** to replace either one with a different file, or reset back to the built-in default.

## Checking you have the latest version

The sidebar footer shows a build label (e.g. "build 2026-save-fix-1"). If you're troubleshooting
an issue with me and I've sent you an updated file, check that label to confirm you're actually
running the new copy and not a previously downloaded one.

## Using the app

- **Import Excel / CSV** — upload `.xlsx`, `.xls`, or `.csv`. Use the **Download Sample Excel
  Template** button there first if you're not sure of the column layout — it includes a worked
  example showing how to enter multiple Internships/Professional Experience entries in one cell
  (`||` between entries, `|` between fields).
- **Add Alumni** — manual entry, with dynamic **+ Add Professional Experience** / **+ Add
  Internship** buttons (each entry is independent and removable), photo upload, Preview CV, and
  Generate PDF.
- **Alumni Records** — search, filter by department, and per record: View, Edit, Preview CV,
  Generate PDF, or Delete. "Generate ZIP (all)" bulk-exports every valid record.
- **Settings** — replace logos, see total record count, export all data to CSV, or clear
  everything.

## Data storage

Records are kept in the browser's local storage on whichever computer/browser you use it on, so
they persist between visits there. For a shared, multi-user setup, use Import Excel/CSV or the
CSV export in Settings to move data between computers.

## PDF output

Each CV is generated by rendering the exact same layout used in "Preview CV" and exporting it as
a PDF (`MUET_Alumni_CV_StudentName_RollNumber.pdf`), so the preview and the download always
match. Long profiles automatically flow onto additional pages rather than being cut off. Email,
phone, and LinkedIn are clickable in the PDF.
